Building segments in HubSpot

Dan Rodgers · Last updated Oct 13

This is how we build the audience for a send. Every send starts from one of my two SYSTEM segments, gets its own copy, and gets named after the ClickUp task. The last part covers random samples, split segments and lookalikes, since we use samples for some of our sends.

The two SYSTEM segments

SegmentWhat it is
SYSTEM - All Marketing ContactsEveryone we're allowed to market to. Filters: Email is known and Marketing contact status is any of Marketing contact. Clone this for every send.
SYSTEM - Master ExcludeThe people who must never get a send: opt-outs and hard bounces. It's used as an exclusion, never as a send list.

Never edit the SYSTEM segments themselves. Clone them. If a SYSTEM segment needs to change, tell me.

Rules for every segment

  • The segment name is the ClickUp task name, exactly. That's how we find it again when someone asks what went out.
  • Every send segment has exclusions applied. Pick one of the two methods below.
  • Check the count before you hand it off. If it looks off, stop and ask.

Build a send segment

There are two ways to keep the wrong people out of a send. Both start the same way.

Start: clone the base segment

  1. Go to CRM > Segments and find SYSTEM - All Marketing Contacts.
  2. Open the Actions menu on its row (or in the segment) and click Clone.
  3. Rename the copy to the ClickUp task name.
  4. Add whatever filters this send needs on top of the two base filters. Keep the base filters in place. If the send is for the whole database, add nothing.

Method A: HubSpot's built-in exclusion rules

HubSpot added an "Additional exclusion rules" section with three toggles. It's collapsed by default, so expand it.

ToggleWhat it doesWhen to turn it on
Exclude non-marketing contactsDrops anyone not marked as a marketing contact.Always
Exclude unsubscribersDrops anyone who has unsubscribed from communications.Always
Exclude email domainsDrops widely used email domains or our own domain, to filter out coworkers.Only when you want our own team out of the audience. Check the domains it's about to exclude before you save. Removing a domain removes every customer on it.

Method B: add SYSTEM - Master Exclude

  1. In the filter panel, scroll to Exclude contacts and turn it on.
  2. Choose Members of a segment.
  3. Select SYSTEM - Master Exclude. You can exclude up to 10 segments, so you can add a send-specific one alongside it (for example, a sponsor's competitors).

This is the one that carries the opt-out and hard bounce filters, so it's the safe default for real sends. I'm fine with using both methods on the same segment.

Save

Click Save. The segment is active at this point, which means HubSpot keeps its membership up to date as contacts change. That's the right behavior for a standard send. It's different from the static segments the sampling tools produce, covered below.

Worked example: a sponsor paid for an email to 40% of the database

A sponsor bought a promotional email. The deal is that it goes to 40% of our marketing database, not everyone. I'll use the ClickUp task name PBX-EM ### Sponsor Promo - [Sponsor] as the stand-in.

  1. Clone SYSTEM - All Marketing Contacts. Name the clone PBX-EM ### Sponsor Promo - [Sponsor] - Source. This is the pool the 40% comes out of, not the send list.
  2. Add exclusions. Use Method A, Method B, or both. For a sponsor send I'd use both, and add the email domains toggle so the sponsor's own staff and ours don't skew the count. Nothing else to filter, because the sponsor is buying the whole database.
  3. Save and write down the count. Say it's 100,000.
  4. On the saved source segment, click Actions > Create random sample.
  5. Enter 40% in the percent field. The record count fills in on its own (40,000 here). Click Create segment.
  6. HubSpot confirms a new static segment was created. Open it and rename it to the exact ClickUp task name.
  7. Check the count is 40% of the source, then use the sample as the send audience.

Two things trip people up:

  • The 40% is 40% of the source segment, which is marketing contacts after exclusions. It isn't 40% of every contact in HubSpot. If the sponsor was promised a specific number, quote them the real count from the source segment.
  • The sample is static. It's a snapshot of who was picked that day. If someone unsubscribes or bounces between now and the send, they stay in the sample, and the source segment moving later doesn't change it. HubSpot still won't email someone who's unsubscribed, but the count will be slightly off. So create the sample on the day of the send, or the day before. Don't build it two weeks ahead.

Each time you take a sample, HubSpot lists the number of samples created on the source segment's Details. If the sponsor wants a second send later, take a fresh sample from the same source and exclude the first sample, so they don't hit the same people twice.

Split segment

Say you want to test two subject lines. Split the source segment 50/50, send one subject line to each half, and compare. If the segment won't divide evenly, the leftover contacts are spread across the splits. Split segments are static, same as samples, so build them close to send time. The difference from a random sample is that a split uses up the whole segment, and the pieces don't overlap.

Lookalike segment

You pick a seed segment and a target size from Specific (closer matches, fewer people) to Broad (more people, looser matches). Generation takes 5 to 15 minutes, and up to an hour for a big database. You can exclude segments such as employees or current leads, and each contact gets a similarity score you can sort by. Lookalikes are for finding people we haven't reached yet, so exclude SYSTEM - Master Exclude and anyone already in the seed. Don't use it for a regular send.

Before you hand off a segment

  1. The name matches the ClickUp task exactly.
  2. Exclusions are on (Method A, B, or both).
  3. The count is what you expected. For a sample, it's the right percentage of the source.
  4. For a sample or split, it was created today or yesterday.
  5. You didn't touch a SYSTEM segment.
