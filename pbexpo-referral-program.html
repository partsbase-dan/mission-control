PBExpo referral program

Dan Rodgers · Launches Monday, Nov 2 · Last updated Oct 7

Every registrant gets their own referral link. When someone registers through it, that registration counts for them. The top referrer each month from November to February wins a Pavilion wristband, and whoever brings in the most people overall wins VIP.

Swapcard doesn't offer attendee referrals in any of its products, so we're not buying anything new. It runs on Launchpad's marketing codes, which we already have. I tested it in September: the code shows up in the Marketing Code report, in the registrant export, and in the Zapier data.

Nobody wins more than one monthly prize. If a past winner tops the list again, the prize goes to the next person. A monthly winner can still win overall, and the VIP wristband just replaces their Pavilion one. Cassandra and I agreed this on Oct 7.

How it works

  1. We load 10,000 codes into Launchpad up front (REF00001 to REF10000). Launchpad only accepts codes it already knows, so this saves anyone creating them by hand.
  2. When someone registers, Zapier gives them the next unused code and logs it against their email in the Zapier table.
  3. Zapier also writes the code to their HubSpot contact, and HubSpot emails them their link: …/register?_mc=REF00417
  4. When someone registers through that link, Launchpad saves the code on the new registration and adds one to that code's count.
  5. The Marketing Code report, sorted by # Confirmed, is the leaderboard. The Zapier table tells us who owns each code.

The catch

The code only sticks if they register in the same visit. If someone clicks a link, leaves, and comes back later through the homepage, the referral is lost. I tested this and it's how Launchpad works, so we deal with it in the copy:

Register using your colleague's link, not the homepage. If you leave and come back later, click the link again so they get credit.

Two things help. The links go straight to the registration form, not the PBExpo homepage. And the "Who referred you?" field is already on the form, so if someone forgets, they can type the code in and we credit it by hand.

Each round takes about half an hour:

  1. Export the Marketing Code report on the last day of the month. It's a running total, so subtract last month's export to get this month's numbers.
  2. For the top three codes, check their registrations in the registrant export. Take out Gmail and other personal emails, students, duplicates, self-referrals, and anything outside the month. Add any hand credits from "Who referred you?".
  3. Look up who owns the winning code in the Zapier table. Skip anyone who's already won a month.
  4. Email the winner within five business days. They have seven days to reply. If they don't, it goes to the next person.
  5. Add the upgrade to their badge in Launchpad and mark the win in the Zapier table. Only announce them publicly if they're OK with it.

February is tight. The challenge closes Friday, Feb 26 and the show opens March 10, so the last two winners get picked on March 1 and have to reply by March 8.
